Программа

Один вечер — один результат

Каждый вечер заканчивается работающей вещью. Что именно останется на руках:

  1. 01
    Рабочее место и первый сайт

    Ставишь инструменты — и первый сайт открывается в браузере в тот же вечер.

    📦 результат: рабочее место + первый сайт в браузере

  2. 02
    Вайбкодинг по-взрослому

    Как ставить агенту задачи, чтобы не переделывать по три раза.

    📦 результат: свой промпт-каркас (готовое задание для нейросети) + чек-лист привычек

  3. 03
    Память проекта: второй мозг

    Нейросеть перестаёт забывать, о чём ты с ней договорился вчера.

    📦 результат: файл памяти CLAUDE.md + папки business, plans, retrospectives

  4. 04
    Скиллы и хуки

    Скилл — сохранённая инструкция агенту, хук — автопроверка: агент сам останавливает опасные действия.

    📦 результат: свой скилл + защита от опасных команд

  5. 05
    В интернет

    GitHub (хранилище кода), хостинг (место, где сайт живёт), база данных.

    📦 результат: сайт по ссылке + приём оплаты

  6. 06
    Автономные агенты

    Агент получает расписание и делает работу, пока ты занят другим.

    📦 результат: агент, который работает по расписанию без тебя

Как устроено обучение

Оплатил — и сразу учишься

мануал

Пошаговый мануал со скринами. Каждый шаг в уроках проверен руками, а не пересказан: открыл, повторил, сверил с картинкой.

помощник

ИИ-помощник в каждом уроке. Застрял — спроси прямо на странице урока, ответит по шагам.

наставник

AI-наставник. Курс скачивается одним файлом: вставь его в Claude — и нейросеть поведёт тебя по шагам, как живой наставник — объяснит, дождётся «сделал», проверит.

кабинет

Кабинет — сразу после оплаты. Система создаёт его сама: логин и пароль придут на почту и в Telegram-бота — там их всегда можно забрать заново.

Как сделан курс. Вопросы, которые ученики задают ИИ-помощнику, складываются в журнал — раз в неделю я прохожу его и переписываю шаги, о которые споткнулись. Поэтому курс с каждой неделей становится подробнее, а не устаревает.
