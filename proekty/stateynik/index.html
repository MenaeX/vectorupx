Статейник: движок знаний

Кладёшь Markdown-файл — получаешь готовые страницы в стиле сайта: оглавление, блок «вопрос — ответ», общий каталог. Раздел «Статьи» этого сайта собран именно им: ноль баз данных, ноль админок — git и один скрипт.

Что ты получаешь

Из простого файла — готовый раздел твоего сайта

Markdown — это обычный текстовый файл с простыми пометками: решётка для заголовка, звёздочки для жирного. Ты кладёшь такой файл в папку, запускаешь один скрипт — и статья появляется на сайте в общем стиле: со своей страницей, оглавлением, блоком «вопрос — ответ» и карточкой в каталоге. Никакой админки, никакой базы данных — только git и один скрипт на Python.

Один скрипт

Вся сборка — одна команда: запускаешь — и скрипт сам собирает тебе страницы, каталог и связи между статьями.

Ноль админок

Никаких баз данных, панелей и подписок. Твой текст живёт в обычных файлах — ты их видишь и легко правишь.

Единый стиль

Каждая страница рождается уже в дизайне твоего сайта: шапка, футер, тёмная тема — тебе не нужно верстать руками.

Как устроено внутри

Путь файла — от папки до страницы

Твоё участие — положить файл и запустить скрипт. Дальше весь маршрут проходит без единого клика в браузере:

1Markdown-файл в папкеобычный текст с простыми пометками
2Скрипт читает файлзаголовки, разделы, блок «вопрос — ответ»
3Собирается страницав общем стиле сайта: шапка, футер, оглавление
4Обновляется каталогкарточка статьи сама появляется в разделе «Статьи»
5Git сохраняет версиюистория правок — бесплатно, без базы данных
6Сайт обновлёнстраницы — обычные файлы, разместишь на любом хостинге

Python-генератор без внешних зависимостей: тебе не нужно ставить сторонние библиотеки — достаточно самого Python.
